| Slug | Use |
|---|---|
| `maintheme/hero` | Main storefront hero. |
| `maintheme/category-grid` | Editable featured category cards. |
| `maintheme/sale-collection` | Products on sale. |
| `maintheme/new-arrivals` | Recent products. |
| `maintheme/best-sellers` | Popular products. |
| `maintheme/promo-split` | Two campaign panels. |
| `maintheme/features` | Store benefits and service promises. |
| `maintheme/testimonials` | Customer quotes. |
| `maintheme/faq` | Details-based FAQ. |
| `maintheme/newsletter` | Newsletter/contact call-to-action. |
| `maintheme/brand-strip` | Brand-name chips. |
| `maintheme/latest-posts` | Store magazine posts. |
| `maintheme/contact-cta` | Support call-to-action. |
| `maintheme/product-trust` | Delivery and return reassurance. |
| `maintheme/shop-empty-state` | Editable no-products state. |

Patterns are starting points. After insertion, their content belongs to the page and can be edited normally.
