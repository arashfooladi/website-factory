# Template map

## Global templates

| File | Purpose |
|---|---|
| `templates/index.html` | Final fallback for posts and archives. |
| `templates/front-page.html` | Static homepage content. |
| `templates/home.html` | Blog posts index. |
| `templates/page.html` | Standard content page. |
| `templates/page-full-width.html` | Full-width editable page. |
| `templates/page-landing.html` | Headerless and footerless landing page. |
| `templates/page-coming-soon.html` | Simple maintenance/launch message. |
| `templates/single.html` | Single blog post. |
| `templates/archive.html` | General archive. |
| `templates/search.html` | General search results. |
| `templates/404.html` | Missing page state. |

## WooCommerce templates

| File | Purpose |
|---|---|
| `templates/archive-product.html` | Main shop/catalog archive. |
| `templates/taxonomy-product_cat.html` | Product categories. |
| `templates/taxonomy-product_tag.html` | Product tags. |
| `templates/taxonomy-product_attribute.html` | Product attributes. |
| `templates/product-search-results.html` | Product-only search results. |
| `templates/single-product.html` | Product detail page. |
| `templates/page-cart.html` | Cart page wrapper; cart block remains in page content. |
| `templates/page-checkout.html` | Checkout page wrapper; checkout block remains in page content. |
| `templates/page-my-account.html` | Customer account. |
| `templates/order-confirmation.html` | Order confirmation. |

## Template parts

| File | Purpose |
|---|---|
| `parts/header.html` | Announcement, branding, product search, account, mini-cart and navigation. |
| `parts/footer.html` | Brand summary, store links, contact data and copyright. |
| `parts/checkout-header.html` | Simplified checkout header. |
| `parts/checkout-footer.html` | Simplified checkout footer. |

A child theme can override any file by copying it to the same relative path. Copy only files that need structural changes.
