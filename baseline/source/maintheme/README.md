# Maintheme 0.4.0

Maintheme is a Persian-first, RTL, full-site-editing parent theme for Iranian WooCommerce stores. It is designed to be the shared visual foundation for multiple independent client websites, each using a small child theme for branding and client-specific templates.

## Distribution files

The release bundle contains:

- `maintheme-0.4.0.zip` — installable parent theme.
- `maintheme-iran-commerce-0.4.0.zip` — recommended Iran-only WooCommerce checkout plugin.
- `maintheme-child-starter-0.4.0.zip` — optional starter child theme.

## Key architecture

- **Parent theme:** layout, design tokens, block templates, patterns and WooCommerce presentation.
- **Iran commerce plugin:** mobile/postcode normalization, country/address rules and checkout validation.
- **Child theme:** brand palette, typography, header/footer variations and client-specific templates.

Start with `docs/INSTALLATION.md`, then read `docs/FEATURES.md` and `docs/CHILD-THEMES.md`.
